# 智慧芽专利浏览追踪助手 (Patsnap Patent Tracker)

专为专利检索分析师设计的 Chrome 扩展插件。通过高精度的**视口交叉观察机制**与**行为捕获**，实现真正的“在屏幕中看过才记录”与“深度详情点击”双态追踪，彻底告别重复浏览与漏检风险。

---

## 🌟 核心功能亮点

1. **精确视口曝光判断 (IntersectionObserver)**：
   - 即使页面加载了 50 篇，**只有真正滑入当前屏幕视口（露出面积 $\ge 50\%$）且持续停留达标的专利**才会被记录。
   - 极速划屏或滚轮扫过的专利会被防抖过滤，坚决杜绝“假已读”造成的漏检隐患。
2. **深度点开详情捕获**：
   - 无论是左键点击公开号、中键滚轮新标签页打开，还是在智慧芽详情页中研读，插件均能自动记录为“已看详情”。
3. **直观双态视觉徽章**：
   - `[👀 已扫过]`（浅灰微标）：提示您视线已扫过，但不抢视线。
   - `[👁️ 已看详情]`（Indigo 品牌色高亮微标）：明确标注该专利已深入研读，无需重复点开。
   - 鼠标悬停徽章自动展示首次曝光与点开的精确时间戳。
4. **专业克制的操作面板 (AUI 规范)**：
   - **统计卡片**：总记录数、已看详情数、仅视口扫过数。
   - **列表已读半透明淡化开关**：一键开启淡化，让新专利在海量列表中脱颖而出。
   - **曝光停留阈值调节**：支持在 0.3s、0.5s（推荐）、1.0s 之间自由切换。
   - **一键导出 CSV**：包含公开号、状态、曝光时间与详情时间，双击即可在 Excel 中编辑，方便直接贴进要素表与检索报告。
   - **精细化清理**：提供“仅清除扫过”（保留研读过的核心专利）与“清空全部”操作。

## 🚀 安装步骤（1 分钟完成）

1. 打开 Chrome 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
2. 在页面右上角打开 **「开发者模式」 (Developer mode)** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**。
4. 在弹出的文件选择器中，选择本插件所在文件夹：
   ```text
   C:\Users\Administrator\.gemini\antigravity\scratch\patsnap-patent-tracker
   ```
5. 安装完成！点击浏览器右上角的拼图图标（扩展程序），将 **「智慧芽专利追踪助手」** 固定（Pin）到工具栏。

---

## 🔍 使用技巧

- **首次使用**：进入智慧芽专利检索列表页，正常滚动浏览，停留在视口内的专利会自动标记为 `[已扫过]`。
- **深入研读**：点击任何公开号进入详情后，返回列表或刷新页面，对应专利卡片会自动升级为 `[已看详情]`。
- **检索复盘**：如果想重新扫描刚才扫过但没深入看的内容，只需点击插件图标，选择 **「仅清除扫过」**，深入看过的记录将依然完好保留！
