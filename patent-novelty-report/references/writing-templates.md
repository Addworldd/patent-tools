# 三段式评述 / 汇总段 / 相关文献表 模板

## 评述格式规范（Addworld 明确指定，已对照参考文件实测确认，必须遵守）

| 元素 | 字体 | 字号 | 颜色 | 加粗 | 下划线 | 背景高亮 |
|---|---|---|---|---|---|---|
| 开篇"相关文献X公开了……，并具体公开了：" | 宋体 | 7.5pt | 黑 | 否 | 无 | 无 |
| 段落号 [XXXX] | 宋体 | 7.5pt | 黑 | 否 | 无 | 无 |
| 原文摘录的关键特征 | 宋体 | 7.5pt | 黑 | 否 | **单线** | 无 |
| 括号评述（含左右括号） | 宋体 | 7.5pt | 黑 | **是** | 无 | 无 |
| 每篇结论"由此可见，公开了检索点X" | 宋体 | 7.5pt | **红 #FF0000** | **是** | 无 | 无 |
| 汇总段"对比可知……建议发明人……" | 宋体 | 7.5pt | 黑 | **是** | 无 | **黄** |
| 列表区标题"相关文献X(公开号，申请人)：" | 宋体 | 9pt | 黑 | **是** | 无 | 无 |

> 渲染 docx 时对应：underline（原文关键特征）/ bold（括号评述、结论、汇总段）/ color=FF0000（结论句）/ highlight=yellow（汇总段）。本文件中用 `<u>…</u>` 表示下划线、`**…**` 表示加粗，颜色/高亮用文字标注。
>
> **不得使用省略号**：完整摘录与比对相关的原文句段（整句/整段，不截断中间），再紧跟括号评述。
>
> **实事求是原则（2026-08-20 P2026439 用户明确）**：评述引用对比文件特征时，**严格以对比文件原文描述为准，不得擅自加概念**。例：CN222565751U 全文只描述"保护套/套体"，从未出现"锥形"，因此评述不得称其为"锥形套"——结论写"公开了检索点①中部分技术特征'尾端范围设置增强结构件（局部加强筋）'"而非"'锥形套尾端…'"。对比文件没描述的概念一律不写。

## 布局规范（2026-08-20 P2026439 用户改稿确认）

- 评述正文与汇总段**都写进表格"检索简要意见"单元格内**（非表格外独立段落）。单元格内顺序：现有技术缺陷 → 本方案发明目的 → 本技术方案/具体技术手段 → 发明点概括 → **经检索后发现：** → 各对比文件评述（开篇/摘录/结论）→ 汇总段。
- 对比文件列表"相关段落"列：习惯填 **"全文"**（不填具体段号）；每条附智慧芽超链接。
- 末尾相关文献标题 `相关文献X(公开号，申请人)：`：**宋体 9pt 加粗**；截图居中、宽约 6.10 英寸（≈15.5cm）。

### 示例（带格式，完整摘录无省略号）

```
相关文献1公开了一种控制舵盘机构及医疗推车，并具体公开了：
[0040]<u>控制舵盘机构100负责收集由操作者传递的运动趋势信号</u>（**相当于移动助力把手**），从而控制两组独立的主动轮的运动速度和方向，实现机器人的前进、后退以及转向。
[0044]舵盘底座110，具有安装区域，可以将第一传感器组件130、第二传感器组件140等<u>安装于该安装区域内</u>（**相当于传感器布置在基座内部**）。
[0047]<u>第一保护弹簧133一方面能够将拉力或压力传递至第一拉压力传感器131</u>（**相当于传感器和把手组件通过弹簧连接**），另一方面第一保护弹簧133产生形变，受到拉伸或挤压行程有限，第一保护弹簧可以将对第一拉压力传感器产生的力限制在一定范围内，使之不超过第一传感器的最大行程保护（**公开了限制行程保护传感器的构思**），第一拉压力传感器131不因力度过大而损坏。
【红色加粗】由此可见，公开了检索点①、检索点②以及检索点③。
```

> 结论句实际渲染为红色加粗；汇总段实际渲染为黄色高亮加粗。

## 措辞二分规则（直接公开 vs 部分公开）

| 情形 | 括号评述写法 | 示例 |
|---|---|---|
| 直接公开（结构/位置/连接实质对应） | `**相当于<本方案特征>**` | `（**相当于基座**）`、`（**相当于传感器布置在基座内部**）` |
| 部分公开 / 功能等同 | `**公开了<对比文件公开的内容>**` | `（**公开了限制行程保护传感器的构思**）` |
| 部分公开（指明对应关系） | `**公开了对应<本方案特征>的<对比文件实现>**` | `（**公开了对应限位结构的销柱限位结构**）` |

- "相当于"只用于直接公开的情形；部分公开一律改用"公开了……"句式，不得写成"相当于"。
- "公开了对应XXX的XXX"中：第一个 XXX = 本方案特征，第二个 XXX = 对比文件中与之对应的实现。

## 单篇评述模板

```
相关文献X公开了一种<技术主题>，并具体公开了：
[段落号] <完整摘录原文句段（关键特征下划线）>（**相当于<本方案特征>**）。
[段落号] <完整摘录原文句段（关键特征下划线）>（**公开了<功能/构思>**）。
[段落号] <完整摘录原文句段（关键特征下划线）>（**结合附图，公开了对应<本方案特征>的<对比文件实现>**）。
……
由此可见，公开了检索点①、检索点②以及检索点③。
```

### 开篇模板
- 直接：`相关文献1公开了一种控制舵盘机构及医疗推车，并具体公开了：`
- 缺申请人时：`相关文献2公开了医疗装置、操纵方法以及可读存储介质，并具体公开了：`

### 正文映射句式库（含格式标记）
| 情形 | 句式 |
|---|---|
| 部件对应 | `（**相当于基座**）`、`（**相当于移动助力把手**）` |
| 位置对应 | `（**相当于传感器布置在基座内部**）` |
| 连接对应 | `（**相当于传感器和把手组件通过弹簧连接**）` |
| 功能等同 / 部分公开 | `（**公开了限制行程保护传感器的构思**）` |
| 部分公开（指明对应） | `（**公开了对应<本方案特征>的<对比文件实现>**）` |
| 带推断依据 | `（**结合附图，相当于……**）`、`（**结合上文，相当于……**）` |
| 检索点子特征 | `（**公开了检索点②中部分技术特征"<原文>"**）` |
| 原理一致 | `（**与助力开关组件的工作过程和原理相同**）` |

### 结论模板（结论句=红色加粗，渲染 color FF0000 + bold）
- 全公开：`由此可见，公开了检索点①、检索点②以及检索点③。`
- 部分：`由此可见，公开了检索点②中部分技术特征"<原文子特征>"以及检索点③。`

## 汇总对比段模板（整段=加粗 + 黄色背景高亮）

```
【黄色高亮加粗】对比可知，检索的现有技术公开了检索点①、②、③、⑤和⑥。
未具体公开检索点如下：
检索点④。
此外，为了进一步提升方案的新创性，建议发明人可从以下方面进行补充：
1、<针对未公开点的完善方向建议>。
```

- 未公开点逐条列出；若全部公开，则表述为"检索的现有技术已公开全部检索点，建议……"并着重提示新颖性风险。
- 补充建议句式参考：完善结构细节、增加具有有益效果的设计、如何布置传感器提高检测灵敏度、如何以简单传感器实现精确检测等。
