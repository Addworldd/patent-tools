# 四类特征映射的判断标准与写作句式

把对比文件的公开内容与本方案检索点逐一比对，判定四类关系。这是评述撰写的技术核心。

## 映射关系总览

| 关系 | 判断标准 | 评述写法 | 结论处理 |
|---|---|---|---|
| 直接对应 | 结构/部件名称、连接关系、动作方式实质相同 | `（**相当于<本方案特征>**）` | 计入"公开了检索点X" |
| 功能等同 / 部分公开 | 结构或实现手段不同，但解决相同技术问题、实现相同功能/构思；或仅覆盖部分子特征 | `（**公开了<功能/构思>**）` 或 `（**公开了对应<本方案特征>的<对比文件实现>**）` | 按"部分公开"表述 |
| 未公开 | 无任何公开内容对应 | 不写入该篇评述 | 留到汇总段"未具体公开"清单 |

> **措辞硬规则**（Addworld 指定）：直接公开才用"相当于"；部分公开一律写"公开了XXX"或"公开了对应XXX的XXX"（前一个 XXX 为本方案特征，后一个为对比文件实现）。不得对部分公开的情形使用"相当于"。

## 各关系判断细则

### 1. 直接对应（用"相当于"）
- 名称相同或高度对应（如"舵盘底座" ↔ "基座"、"把手组件" ↔ "把手组件"）。
- 连接关系、空间位置一致（如"安装于安装区域内" ↔ "布置在基座内部"）。
- 写作：`（**相当于基座**）`、`（**相当于传感器布置在基座内部**）`。映射词用"相当于"。

### 2. 部分公开 / 功能等同（用"公开了……"句式）
- 结构/部件不同，但解决同一问题、实现同一功能或构思（如对比文件用"销柱+孔"限位 ↔ 本方案"限位结构"限位）→ 写 `（**公开了限制行程保护传感器的构思**）`。
- 需要指明对应关系时 → 写 `（**公开了对应<本方案特征>的<对比文件实现>**）`，如 `（**公开了对应限位结构的销柱限位结构**）`。
- 判定要件：功能相同 + 解决的问题相同。仅功能相似但解决的问题不同，不构成公开。
- 隐含推断（需结合附图/上下文才能确认）必须注明：`（**结合附图，公开了……**）`、`（**结合上文，相当于……**）`。

### 3. 部分公开
- 对比文件公开了某检索点的部分特征，但缺关键子特征（如公开了"阻尼感+复位效果"，未公开"吸能减震"）。
- 写作：`（公开了检索点②中部分技术特征"在把手移动时提供阻尼感，弹簧本身也能带来一定复位效果"）`。
- 子特征引用原文，加引号，忠实原文表述。

### 4. 未公开
- 通读全文后无对应内容，或仅有不相关的泛化表述。
- 处理：不写入该篇评述，避免凑数；在汇总段列入"未具体公开检索点"。
- 例外：若某检索点没有任何文献公开，务必在汇总段单独列出并说明，作为新创性结论依据。

## 常见错误规避

1. **过度等同**：把"功能相似但目的不同"写成公开——必须同时满足功能与所解决问题一致。
2. **无依据推断**：不写"结合附图/结合上文"就断言结构对应——评述须可复核。
3. **原文失真**：括号外摘录改动原意、拼接断章——引用须忠实，完整摘录相关句段；**不得使用省略号截断原文**。
4. **结论虚高**：仅部分公开却写"公开了检索点X"——按部分公开精确表述。
5. **漏检未公开点**：汇总段未列未公开清单——未公开点是新创性结论核心，必须完整。
