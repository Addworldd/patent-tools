# 查新报告填写（对比文件评述 + 检索式生成 + 填表）

## Overview

依据"发明点/检索点"与对比文件全文，撰写《检索记录表》（查新报告）中"对比文件公开内容评述"字段，生成检索式清单，并回填完成整份报告。核心产出顺序：评述 → 汇总结论 → 检索式 → 填表。

## 工作流

1. **读取输入**：获取报告（含发明点概括/检索点编号、背景技术）与对比文件全文（用户提供 PDF/文本/交底材料；若只有公开号，可经智慧芽通道拉取全文）。
2. **拆解检索点**：将"发明点概括"逐条编号为检索点①~⑥（每条 = 一个可独立比对的检索点，评述的锚点）。检索点编号沿用报告原有编号，不另起。
3. **建立特征映射**：对每篇对比文件，通读全文，抽取与检索点相关的段落（引用时标注原文段落号 [XXXX]），按四类关系判断对应：直接对应 / 功能等同 / 部分公开 / 未公开。判断标准与句式见 `references/mapping-rules.md`。
4. **撰写三段式评述**：每篇对比文件独立成段——开篇（公开了X）→ 正文（原文摘录 + 括号映射）→ 结论（公开了检索点X）。模板见 `references/writing-templates.md`。
5. **多篇汇总**：全部检索点 × 全部文献取并集，得出"已公开清单"与"未公开清单"。**未公开检索点 = 新创性支撑点**，是整份报告的结论核心。
6. **生成检索式**：围绕未公开检索点 + 核心技术特征构造：①语义检索式（SEMANTIC 全要素描述）；②字段检索式（IPC + 关键词 + 逻辑运算符，中英文联合）。每条记录：序号、检索式、数据库、命中组数。规范见 `references/search-query-rules.md`。
7. **回填交付**：把评述、检索式、相关文献列表（类型/文献号/公开日期/相关段落）回填到报告对应栏目；"检索要点"沿用用户填写的发明点+背景技术，不做改动。交付格式按用户约定（默认直接回填原报告 docx）。
8. **相关文献截图（评述确认后，统一走网页路线）**：评述文字经用户确认后，为每篇对比文件生成【相关文献X(公开号，申请人)：】标题 + 对应内容高亮截图（黄色高亮，截取范围=高亮段落前后各两段），插入 docx 相关文献区。**截图一律采用智慧芽网页高亮截图路线**（浏览器自动化，经 web-access skill 的 CDP 代理执行；已实测跑通并复跑验证 PASS）。**规范与完整步骤已迁移至独立 skill `zhihuiya-highlight-shot`（references/screenshot-spec.md 与 site-zhihuiya.md），执行时激活该 skill。**申请人信息从智慧芽链接对应摘要页获取。

## 关键规则

- 引用忠实原文，逐段标注段落号（[0040] 等），不臆造原文内容。
- **实事求是原则**（2026-08-20 用户明确）：评述引用对比文件特征时严格以原文描述为准，**不得擅自加概念**。对比文件未描述"锥形"就不得称"锥形套"（例：CN222565751U 只描述"保护套/套体"，结论写"公开了检索点①中部分技术特征'尾端范围设置增强结构件（局部加强筋）'"而非"'锥形套尾端…'"）。对比文件没描述的概念一律不写。
- **布局**（2026-08-20 用户改稿确认）：评述正文与汇总段写入表格"检索简要意见"单元格内（非表格外）；对比文件列表"相关段落"列填"全文"。
- **格式规范**（Addworld 指定，已对照参考文件《P2026288 检索记录表》及 P2026439 用户改稿实测确认）：
  - 正文（开篇/段落号/摘录叙述）：宋体 7.5pt，黑色，常规；
  - 原文摘录关键特征：**单线下划线**（不加粗、无颜色）；
  - 括号评述（含左右括号）：**加粗**（无下划线、无颜色）；
  - 每篇结论句"由此可见，公开了检索点X"：**红色(#FF0000)加粗**；
  - 汇总段"对比可知……建议发明人可从以下方面进行补充"：**加粗 + 黄色背景高亮(highlight)**
  - 相关文献列表区标题"相关文献X(公开号，申请人)："：宋体 9pt **加粗**。
  - 渲染 docx 时对应：underline / bold / color FF0000 / highlight yellow。
- **措辞规范**（Addworld 指定）：直接公开用"相当于"，如 `（**相当于基座**）`；部分公开用"公开了XXX"或"公开了对应XXX的XXX"（前一个 XXX 为本方案特征，后一个为对比文件实现），如 `（**公开了限制行程保护传感器的构思**）`。部分公开情形不得使用"相当于"。
- **摘录规范**（Addworld 指定）：评述中**不得使用省略号**截断原文；完整摘录与比对相关的原文句段后，再进行评述。
- 隐含推断必须注明依据，如 `（**结合附图，相当于……**）`。
- 每篇评述结尾落到"由此可见，公开了检索点X"；未公开的检索点不写入该篇，留到汇总段。
- 检索式命中数如实记录（智慧芽按组数），不编造。
- 若对比文件为外文，按专利翻译规范转写引用，术语统一。
