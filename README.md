# 专利分析与检索专属实战工具箱 (Patent Analysis & Retrieval Toolkit)

专为专利检索分析师、代理师与审查员打造的一站式实战工具合集。

---

## 📦 模块导航

| 模块目录 | 核心功能定位 | 运行形态 |
| :--- | :--- | :--- |
| **[patent-anno-share/](./patent-anno-share)** | **智慧芽中英对照批注生成器**：免登录分享链接提取、DeepSeek 专业大模型翻译与质量门禁、单文件离线 HTML 生成、附图内嵌与双向批注流转。 | 本地 WebUI + 独立 EXE + CLI |
| **[patent-novelty-report/](./patent-novelty-report)** | **专利查新分析报告套件**：现有技术深度比对、权利要求原子化拆解、法定三态判定与 Word 报告原生在位排版（杜绝软换行）。 | Python CLI / 报告流水线 |
| **[zhihuiya-highlight-shot/](./zhihuiya-highlight-shot)** | **智慧芽高亮截屏工具**：多特征高亮对齐、长图与证据图智能抓取、自动化在位嵌入 Word 报告。 | 本地 GUI / 批处理 |
| **[patsnap-patent-tracker/](./patsnap-patent-tracker)** | **智慧芽浏览与研读追踪助手**：高精度视口停留曝光（防抖过滤假已读）、深度点开详情捕获、已读淡化与一键导出 CSV。 | Chrome 原生扩展插件 |
| **[doubao-patent-agent/](./doubao-patent-agent)** | **豆包专利自动化 Agent**：基于 CDP 协议的浏览器自动化交互与智能检索实验工具。 | Python CDP 自动化脚本 |

---

## 🛠️ 环境要求
- Windows 10/11
- Python 3.11+
- Google Chrome 浏览器
